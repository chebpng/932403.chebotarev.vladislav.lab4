# 932403.chebotarev.vladislav.lab4

Лабораторная работа №4. Основы JavaScript
Цель: познакомиться с синтаксисом JS, базовыми конструкциями и логикой.

Задание:
Добавить на страницу скрипт (script.js), который реализует:
- ввод/вывод: prompt (имя), alert (приветствие), console.log;
- условные конструкции и циклы;
- функции для поиска максимума, фильтрации и подсчёта суммы в массиве.

Вариант 10. Тема «Книжный червь и писатель» (страницы в день). Данные: массив из
5–7 чисел — количество прочитанных страниц в день.

Логика варианта:
- фильтрация — дни с > 50 страницами;
- цикл — «ленивые» дни (≤ 20 страниц) и их доля;
- функции: максимум, фильтрация, сумма;
- вывод: alert — «Всего прочитано X страниц, в Y днях темп был высоким»;
- console — доля «ленивых» дней и их количество;
- дополнительно: если среднее > 40 страниц, консоль — «Отличный темп чтения!».

Реализация:
- `index.html` — разметка страницы из лабораторной №3, дополненная секцией
  «Статистика чтения» и подключением `script.js`;
- `style.css` — стили страницы, включая оформление блока статистики;
- `script.js` — массив `dailyPages`, функции `findMax`, `filterPages`,
  `countLazyDays`, `sumPages`, вывод в `alert` и `console`, заполнение карточек
  статистики на странице.

Данные варианта: `[35, 78, 12, 54, 90, 18, 63]`.
